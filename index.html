05 / RESPONSIBLE USE

Designed to be useful, not misleading.

This interface never invents a cancer result. If no inference API is configured, it clearly tells the user why analysis cannot run. A real clinical workflow requires validated data, model evaluation, calibration, external validation and appropriate professional oversight.
